# El Amor Bloom

EL AMOR GARDEN KIGALI

Immersive Digital Experience — Master Design & UX Specification

You are building the complete website experience for El Amor Garden Kigali, a botanical lifestyle, gardening, edible-greens, and Made-in-Rwanda decor brand in Kigali.

This is NOT a normal business website.

This is NOT a generic plant catalogue.

This is NOT a template with animations added on top.

The objective is to create a premium interactive digital experience that makes the visitor feel as if they are entering the world of El Amor Garden.

The website should feel closer to an interactive editorial / digital art experience than a conventional company website.

The inspiration level is the craftsmanship, interaction quality, storytelling, motion, and spatial composition seen in sites such as Pear and Igloo Inc., but the final design must be completely original and specific to El Amor Garden.

1. THE CENTRAL IDEA

The entire website should communicate one idea:

El Amor Garden is not simply selling plants. It creates experiences around greenery, living spaces, gardens, food, craftsmanship, and everyday life.

Therefore, do not structure the website around:

Home → About → Services → Products → Contact.

Instead, structure it around an experience.

The visitor should feel like they are progressively discovering El Amor.

The journey should feel like:

ENTER → DISCOVER → EXPLORE → EXPERIENCE → CONNECT → VISIT

The website should have moments of surprise.

The visitor should occasionally think:

“Oh, that's interesting.”

rather than:

“Okay, another website section.”

2. PRIMARY UX OBJECTIVES

Every design decision should serve these goals:

Goal 1 — Create immediate emotional impact

Within the first few seconds, the visitor should understand that this is a special botanical brand.

Goal 2 — Make discovery enjoyable

Visitors should want to explore instead of simply scrolling past sections.

Goal 3 — Communicate the business quickly

The visitor should understand that El Amor offers:

plants

edible greens

landscaping

garden design

plant care

handmade decor

gifts

without reading long paragraphs.

Goal 4 — Convert naturally

The website should make contacting El Amor extremely easy.

Primary conversion:

WhatsApp

Secondary conversions:

Visit the Garden

Explore Instagram

Request a Quote

Goal 5 — Make El Amor memorable

The website should give the business an identity that Instagram alone cannot provide.

6. VIEWPORT COMPOSITION

Whenever possible, each major section should behave like a complete visual frame.

The visitor should not have to scroll through enormous empty spaces just to understand a section.

Aim for:

+
TITLE
+
SHORT DESCRIPTION
+
CTA

Do not force every section to exactly 100vh.

Instead:

eliminate unnecessary vertical space and make each section visually complete.

27. MOTION LANGUAGE

Create one coherent motion language.

Motion should feel:

slow + organic + precise + confident.

Not:

fast + flashy + playful + random.

Use easing that feels natural.

Avoid excessive spring/bounce animations.

Do not animate every element.

Some elements should simply exist.

28. RESPONSIVE EXPERIENCE

Mobile is NOT a secondary version.

Instagram traffic is likely to be important.

Create a deliberate mobile experience.

On mobile:

floating navbar remains compact

typography scales intelligently

images remain immersive

sections stay compact

horizontal overflow is intentional only where designed

touch interactions replace hover

CTAs remain easy to access

motion remains lightweight

Do not simply stack the desktop layout vertically.

29. PERFORMANCE

Despite the rich experience, the site must remain fast.

Use:

optimized AVIF/WebP

responsive image sizing

lazy loading

static generation where possible

minimal client-side JavaScript

dynamic imports for heavy 3D

load WebGL only when needed

GPU-friendly transforms

IntersectionObserver

optimized fonts

no unnecessary dependencies

The site should feel fast before it feels impressive.

Ideally target excellent Lighthouse scores.

37. QUALITY BAR

Do not stop when the website is technically complete.

Perform a visual QA pass.

Look at every section and ask:

Does this feel generic?

Is there too much empty space?

Is this heading unnecessarily large?

Does the image support the typography?

Is the interaction meaningful?

Is this section visually different from the previous one?

Does this feel like an experience?

Does this feel like El Amor?

Could another AI-generated website look exactly like this?

If the answer to the last question is yes:

redesign that section.

The final website should feel like:

A premium interactive botanical world built around El Amor Garden — not a website template with plants inside it.

Build the experience first. Explain decisions only after implementation.
